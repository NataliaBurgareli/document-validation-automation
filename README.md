# 📄 Document Validation Automation

Automated document validation using Python, Playwright, and Excel.

## 🚀 Overview

This project automates the analysis of document-based requests by:

- 📥 Reading request data from an Excel file
- 🌐 Opening document repository links automatically
- 📎 Counting attached documents
- 📊 Generating an output report
- ⚡ Reducing manual effort and validation time

## ✨ Features

- ✅ Excel input processing
- ✅ Automated browser navigation
- ✅ Document attachment counting
- ✅ Output report generation
- ✅ Identification of requests with incomplete documentation

## 🛠️ Technologies

- 🐍 Python
- 🎭 Playwright
- 🐼 Pandas
- 📗 OpenPyXL

## 🎯 Business Value

This automation helps teams:

- ⏱️ Reduce manual validation effort
- 🔍 Quickly identify requests with missing documentation
- 📈 Improve operational productivity
- 🎯 Focus on more complex cases
- 📋 Support SLA compliance
